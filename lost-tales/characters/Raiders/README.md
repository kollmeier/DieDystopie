# Raider

## Beschreibung

Die Raider sind Gruppierungen an der Oberfläche, die davon leben Bunker zu überfallen ("raiden"). Die Raider-Gruppe um Bunker 9 wird einfach als "Die Raider" bezeichnet, obwohl es natürlich auch um die anderen Bunker Raider gibt.
