# Bunker 9, Block 2
_Alternative Schreibweise: Block 9/2_

## Beschreibung
Der zweite Wohnblock im Bunker 9. Die Bewohner sind eine Überzeichnung unserer Gesellschaft mit besonderem Blick auf übermäßig regelkonforme Bürger und regelkritische Bürger.

Die Bewohner wohnen beschützt unter der Erde und sind in der Regel erkennbar an ihren blauen Overalls mit gelben Trennstreifen.
